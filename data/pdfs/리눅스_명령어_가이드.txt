리눅스 기본 명령어 가이드

1. 파일 및 디렉토리 관리
ls: 현재 디렉토리의 파일 목록을 표시합니다. ls -la 옵션으로 숨김 파일과 상세 정보를 볼 수 있습니다.
cd: 디렉토리를 이동합니다. cd ~ 은 홈 디렉토리로, cd .. 은 상위 디렉토리로 이동합니다.
mkdir: 새 디렉토리를 생성합니다. mkdir -p a/b/c 로 중간 디렉토리를 자동 생성할 수 있습니다.
cp: 파일을 복사합니다. cp -r 옵션으로 디렉토리 전체를 복사할 수 있습니다.
mv: 파일을 이동하거나 이름을 변경합니다.
rm: 파일을 삭제합니다. rm -rf 는 디렉토리를 강제로 삭제하므로 주의가 필요합니다.

2. 파일 내용 확인
cat: 파일 내용을 전체 출력합니다.
head: 파일의 처음 10줄을 출력합니다. head -n 20 으로 줄 수를 지정할 수 있습니다.
tail: 파일의 마지막 10줄을 출력합니다. tail -f 옵션으로 로그 파일을 실시간 감시할 수 있습니다.
grep: 파일에서 특정 패턴을 검색합니다. grep -r 은 디렉토리 전체를 재귀적으로 검색합니다.

3. 권한 관리
chmod: 파일 권한을 변경합니다. chmod 755 file.sh 로 실행 권한을 부여합니다.
권한은 읽기(r=4), 쓰기(w=2), 실행(x=1)의 합으로 표현됩니다.
chown: 파일 소유자를 변경합니다. chown user:group file 형식으로 사용합니다.

4. 프로세스 관리
ps: 현재 실행 중인 프로세스를 표시합니다. ps aux 로 모든 프로세스를 볼 수 있습니다.
kill: 프로세스를 종료합니다. kill -9 PID 로 강제 종료할 수 있습니다.
top: 시스템 리소스 사용량을 실시간으로 모니터링합니다. CPU, 메모리 사용률을 확인할 수 있습니다.
